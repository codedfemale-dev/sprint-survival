# Sprint Survival has moved

Sprint Survival is now maintained as one game in the [Coded Female Arcade](https://github.com/codedfemale-dev/coded-female-games/tree/main/sprint-survival).

**[Play Sprint Survival](https://codedfemale-dev.github.io/coded-female-games/sprint-survival/)** · [All arcade games](https://codedfemale-dev.github.io/coded-female-games/)

This repository only preserves the old play address as a redirect. The engine, scenarios, graphics, educational content, tests and future updates all live in the arcade repository. Previous standalone source remains in this repository’s Git history.

The consolidated game retains the purple-and-lime studio, team and duck, all six stories (22 situations), branching consequences, educational explanations, replay and save/resume. Both play addresses use the same GitHub Pages origin and namespaced localStorage key, so existing browser saves remain available after redirecting.

Do not add a second game implementation here. Make game changes in `coded-female-games/sprint-survival/`.
